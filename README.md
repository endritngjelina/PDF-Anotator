# PDF-Annotator

A browser-based PDF annotation application for viewing and working with PDF documents directly in the web browser.

## Overview

**PDF-Annotator** is a lightweight web project focused on making PDF documents easier to view and annotate without requiring a dedicated desktop application.

The repository contains multiple versions of the application, allowing different iterations of the PDF annotator to be maintained and tested.

## Features

* 📄 PDF document viewing
* ✏️ PDF annotation capabilities
* 🌐 Browser-based interface
* 💻 No dedicated desktop application required
* 🔄 Multiple versions available for development and testing
* 🪶 Lightweight HTML-based implementation

## Getting Started

Since the application is built as an HTML-based web project, it can be run locally without a complex setup.

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/PDF-Annotator.git
```

### 2. Open the application

Navigate to the project directory and open any of the HTML files in a modern web browser.

For example:

```text
pdf annotator 5.html
```

You can also serve the project through a local development server if desired.

## Usage

1. Open one of the HTML application files.
2. Load or view a PDF document.
3. Use the available annotation functionality to work with the document.
4. Select the version of the application that best fits your needs.
